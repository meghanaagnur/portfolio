# Footer Design Concept & References

Saved for upcoming footer build as requested by user.

## Design Vision
Combine the two reference images:
1. **Layout & Typography**: Inspired by `planes-footer.png` (Planes by Ashish Gogula):
   - Brand column with tagline: "Meghana — Frontend Developer & Builder. Exploring clean interfaces & applied AI."
   - Multi-column navigation links (Browse / Projects / Experience / Connect).
   - Copyright line + social links (GitHub, LinkedIn, X, Mail).
   - Huge, architectural statement typography across the bottom edge (e.g. "MEGHANA" or "PORTFOLIO") with subtle gradient / noise.
2. **Visual Graphic / Texture**: Inspired by `dither-portal.jpg`:
   - Mesmerizing halftone / dithered wave distortion / portal effect integrated smoothly into the footer card or background.
   - Works seamlessly in both dark mode (glowing dithered portal) and light mode.
