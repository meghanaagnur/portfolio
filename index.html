VaariSarthi

A safety net for the Wari, so no pilgrim walks lost.

A hackathon prototype for Warkaris on the 250 to 300km Pandharpur Wari, where pilgrims get separated from their group with no way to track individuals. Our team designed it around group tracking with drift alerts, lost and found matching, an emergency SOS flow, and a bilingual Marathi/English interface.

02 FINALIST · TOP 68 TEAMS

Codence

Every PR has a reason. Codence makes sure it's not lost.

A team project that captures the reasoning behind code decisions at PR time through short AI voice interviews, and stores the answers as searchable decision records, so a team can ask “why was this built this way?” and get a sourced answer.

My role Built the Next.js frontend and worked with ChromaDB and Ollama for the search. Finalist at Synapse 1.0, SIT Pune.

Next.js Tailwind Node.js ChromaDB Ollama
03 PROTOTYPE

VibeCheck

AI writes the code. VibeCheck checks if it actually listened.

Catches gaps between an AI coding prompt and what actually renders, using a deterministic diff engine instead of asking another AI to judge, so the check doesn't rely on the same kind of model it's checking.

My role Led the project and built the frontend; a teammate built the Playwright diff engine. Not deployed yet.

Next.js Node.js Playwright Python
